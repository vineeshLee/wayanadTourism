# Wayanad Tourism Website

A modern, responsive website showcasing the natural beauty, attractions, and tourism offerings of Wayanad, Kerala.

## Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Photo Gallery**: High-quality images of Wayanad's stunning landscapes
- **Destination Guide**: Information about top destinations including Chembra Peak, Pookot Lake, Banasura Dam, and more
- **Attractions**: Detailed information about must-see attractions and activities
- **Hotel Listings**: Curated selection of hotels, resorts, and homestays with pricing
- **Contact Form**: Easy way for visitors to get in touch
- **Mobile Menu**: Hamburger menu for mobile navigation
- **Smooth Scrolling**: Enhanced user experience with smooth scroll animations

## Technologies Used

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Build Tool**: Vite
- **Images**: Unsplash (high-quality tourism images)

## Project Structure

## Installation

1. Clone the repository or navigate to the project directory
2. Install dependencies:
   ```bash
   npm install
   ```

## Development

Start the development server:
```bash
npm run dev
```

The website will automatically open in your default browser at `http://localhost:5173`

## Build

Create a production build:
```bash
npm run build
```

The optimized files will be generated in the `dist` directory.

## Preview

Preview the production build locally:
```bash
npm run preview
```
