# Screenshots Directory

This directory contains screenshots of the Wayanad Tourism website for documentation purposes.

## Required Screenshots

Please add the following screenshots to this directory:

### Desktop Screenshots (1920x1080 or similar)
- `desktop-homepage.png` - Full homepage view showing hero section and navigation
- `desktop-destinations.png` - Destinations section with all 6 destinations visible

### Mobile Screenshots (375x667 or iPhone SE size)
- `mobile-homepage.png` - Mobile homepage with hamburger menu
- `mobile-gallery.png` - Mobile photo gallery view

### Feature Screenshots
- `chatbot-interface.png` - Dify chatbot interface in action

## How to Capture Screenshots

### Desktop Screenshots
1. Open the website in Chrome/Firefox at full screen (1920x1080)
2. Use browser dev tools to simulate different viewports if needed
3. Take full page screenshots using:
   - Chrome: Ctrl+Shift+P → "Capture full size screenshot"
   - Firefox: Right-click → "Take Screenshot" → "Save full page"

### Mobile Screenshots
1. Open browser dev tools (F12)
2. Toggle device toolbar (Ctrl+Shift+M in Chrome)
3. Select iPhone SE or similar mobile device
4. Take screenshots of key sections

### Chatbot Screenshots
1. Click the chat bubble in bottom-right corner
2. Take screenshot of the opened chat interface

## File Naming Convention
- Use lowercase with hyphens: `desktop-homepage.png`
- Include device/screen size in filename when relevant
- Keep file sizes under 500KB for web optimization

## Tools for Screenshots
- **Browser DevTools** - Built-in screenshot tools
- **Snagit** - Professional screenshot software
- **Lightshot** - Quick screenshot tool
- **Native OS tools** - Windows Snip & Sketch, macOS Screenshot

## Optimization
- Compress images using TinyPNG or similar
- Convert to WebP format for better compression
- Maintain aspect ratios for consistent display
